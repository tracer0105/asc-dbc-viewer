==============================================================
  ASC → 交互式曲线  v1.1.0   （免安装版）
==============================================================

【这是什么】
把 Vector ASC（CAN / CAN FD）报文日志 + DBC 矩阵，解码成**单个离线 HTML**：
左侧信号树、右侧多曲线（各自独立 Y 轴）、悬停十字线读数、滚轮缩放、拖动平移、导出 CSV。
不联网、不用装 CANoe，双击 HTML 就能看。

同一个 DBC 可以对应**一份或多份** ASC，三种玩法在下面第 3 节。

【怎么用】
方式 1（推荐）双击 ASC交互曲线.exe → 图形界面里选 asc（可按住 Ctrl/Shift 多选）、
       选 dbc → 点“生成”。多份日志时勾选“多个日志合并为一张图”。
方式 2 把 .asc 文件拖到 ASC交互曲线.exe 图标上（可多选一起拖，同目录有 dbc 自动配对）。
方式 3 命令行（可脚本化）：
       ASC交互曲线.exe  日志.asc  矩阵.dbc  -o 输出.html
       常用参数：
         --ids 10C,32B          只处理指定报文 ID
         --signal MotSpd        只输出名称匹配正则的信号（可写 报文名.信号名）
         --from 100 --to 200    只取某段时间（秒，累计后的时间轴）
         --max-points 6000      每条信号的采样点（越大越精细、文件越大）
         --no-dbc               忽略 DBC，按 ID+字节看原始报文
         --no-rebase            不修正时间戳重置
         --open                 生成后打开浏览器
       完整帮助： ASC交互曲线.exe --help

【多份 ASC：批量 vs 对比】
1) 批量出图（默认）：每个 ASC 各自生成一个 HTML
   ASC交互曲线.exe run1.asc run2.asc 矩阵.dbc
   ASC交互曲线.exe run1.asc run2.asc 矩阵.dbc -o 输出目录
   —— 输出目录不存在会自动创建。

2) 合并成一张“对比图”：同一个信号只占一行，多份日志用不同颜色叠加
   ASC交互曲线.exe run1.asc run2.asc 矩阵.dbc --merge -o 对比.html
   - 每份日志的时间轴各自从 0 开始（便于对齐形状比较），总时长取最长的一份
   - 右上角有图例（文件名 ↔ 颜色），左侧每个信号前的小色块表示命中几份日志
   - 悬浮读数会分别列出每个文件的数值
   - 导出 CSV 时列名形如 M1.Speed[km/h]@run1

   注意：批量模式下 -o 必须给“目录”，给 .html 会报错并提示加 --merge。

【运行环境】
已内置 Python 3.14 + python-can + cantools + tkinter，
无需安装 Python、无需联网、不写注册表。适用 Windows 10 / 11 64 位。
首次运行或大文件会有 2~5 秒启动（单文件程序要先解压到临时目录）。

【界面操作】
滚轮 = 时间轴缩放（以鼠标为中心）
拖动 = 平移；双击 或 按 0 = 复位；左右方向键 = 平移
悬停 = 竖线 + 每条信号（叠加模式下每个文件）的当前值
“导出 CSV” = 按当前可视区间均匀采 5000 点导出（采样保持）
左侧搜索框 = 按信号名 / 报文名 / ID 过滤

【常见问题】
1) 杀毒软件拦截：单文件 exe 首次运行易被误报，加入信任即可。
2) 曲线在时间轴上反复跳回 0：日志是分段录制的，程序默认已自动累加，
   标题栏会显示“时间戳重置 N 次”。注意累计后总时长≠真实墙钟时长。
3) 解码失败数很大：DBC 版本与实车固件不一致，换对应矩阵；
   想先看报文本身可加 --no-dbc。
4) 某些信号明显不对（量程/符号对不上）：多为矩阵本身定义问题
   （重叠/别名/超出报文长度）。程序会自动修最常见的几种，日志里会提示。
5) 文件太大很慢：用 --ids / --signal / --from --to 缩小范围，或调低 --max-points。
   两份 65 MB 日志合并约需 1.5 分钟、产出的 HTML 约 31 MB。
6) 打不开/闪退：把 exe 放到非中文、非 OneDrive 路径再试；
   或在命令行运行以看到完整报错。
